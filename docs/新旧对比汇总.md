# 新旧对比汇总：旧版 Web → 提示词 v1.4 → 安卓端

> 本文档用于记录「星眸训练台」安卓版在迁移过程中，旧版 Web 端与《启智星图 AI Agent 提示词优化版 v1.4》之间的差异与裁决结果。
>
> **裁决原则：旧版与提示词冲突时，一律采用提示词。**
>
> 更新时间：2026-09-22

---

## 0. 三份输入

| 输入 | 说明 |
|---|---|
| **旧版 Web** | `QizhiTrainingPlatform-Portable`，启智训练台便携版，原生 HTML/CSS/JS + 本地 Python/SQLite/Ollama |
| **提示词 v1.4** | `启智星图_AI提示词优化(1).md`，AI Agent 行为规范 + 三端口输出 JSON Schema |
| **技术决策** | 单机 + 直连云端 DeepSeek + Kotlin/Jetpack Compose + Room + 三端口（child/parent/professional） |

## 1. 冲突裁决表（采用提示词）

| # | 冲突点 | 旧版 Web | 提示词 v1.4 | **裁决** | 安卓端落地 |
|---|---|---|---|---|---|
| C1 | 角色命名 | `teacher`（康复专业人员） | `professional`（专业人员） | ✅ professional | `Port.PROFESSIONAL`（[Models.kt](../app/src/main/java/com/xingmou/core/model/Models.kt)） |
| C2 | AI 载体 | 本地 Ollama `qwen3:0.6b` | 架构中立，要求知识库检索 + 确定性降级 | ✅ 云端 DeepSeek | `DeepSeekClient` + 本地知识库 |
| C3 | 方案生效机制 | 实名签署 + 历史版本不覆盖 | `draft → confirmed → active` + `review_required=true` | ✅ 提示词状态机 | `PlanStateMachine` |
| C4 | 安全风险清单 | 6 类（seizure/selfHarm/aggression/meltdown/swallowing/fall） | 9 类（另加：意识异常、明显发育倒退、走失/陌生人、疑似急症） | ✅ 提示词 9 类 | `RiskEngine` 扩展 |
| C5 | 数据充分性阈值 | 无硬阈值（ai.js 取最近 10 条） | 有效记录 **< 3 条不做能力结论** | ✅ 提示词 3 条阈值 | `AnalysisEngine` |

## 7. 遗留差异说明

1. **知识库来源**：提示词要求 `approved_knowledge` 可检索、可溯源。云端直连 + 无后端下，知识库只能**本地内置**（旧版 12 方法 + 15 量表作种子）。若要动态扩充知识库，需回到"轻后端"方案——这是唯一可能推翻"纯单机"的模块。
2. **API Key 安全**：单机直连 DeepSeek 的 Key 会打包进 APK，反编译可提取。折中：Key 放 `local.properties`/Keystore 且不入库（`.gitignore` 已排除），但并非"绝对不泄露"。
3. **旧版治理模块（机构/内容版本/共享授权/备份）在单机版暂缓**：这些依赖服务端数据库能力，安卓单机版第一阶段裁剪，后续可恢复。
