# 机构 API Key 设置与纯前端直连说明

本项目是 Android 单机应用，没有自有服务端。DeepSeek Key 由使用者在 App 内运行时填写，App 直接请求 DeepSeek；不在构建配置或 APK 内预置 Key。

## 使用步骤

1. 进入“专业端”，点击顶部“机构 API Key”。
2. 在“API Key 设置”输入由使用者自行管理的 DeepSeek Key，点击“保存”。界面只显示配置状态，不回显完整 Key。
3. 切换到要操作的儿童，点击顶部“授权”，打开该儿童的“远程 AI”同意。未授权儿童、未同意或未设置 Key 时仅使用本地安全模式。
4. 家长端提交具体观察，或专业端生成待审核方案草案；请求通过本地规则和脱敏后直连 DeepSeek。无网络、超时、HTTP 错误或 JSON/来源校验失败时使用本地安全结果。
5. 不再使用该 Key 时，回到“机构 API Key”点击“清除已保存 Key”。清除只阻止后续请求，不能撤回已经发送的请求或替 Key 持有人取消平台账单。

## 风险与边界

- Key 保存在本机私有设置中，可能被设备所有者、Root 环境、恶意软件或调试手段提取。`android:allowBackup=false` 仅减少常规备份暴露，不提供服务端级保密能力。
- 费用没有服务端配额保障。App 限制输入长度、单次输出 token 和超时；实际额度、账单与封禁由 Key 持有人在 DeepSeek 平台管理。
- 远程 AI 不是诊断工具；专业草案必须人工审核签署。当前本地角色切换不等于服务端强身份认证。
- 不要将 Key 写入聊天、截图、Git、`local.properties` 或普通日志。若旧 Key 曾在聊天中分享，建议在平台撤销并换新。

## 验证边界

常规自动测试使用虚构测试 Key 和本地模拟 HTTP 响应，不会调用真实 DeepSeek。另有可选 `DirectDeepSeekLiveSmokeTest`，只有显式设置临时环境变量 `DEEPSEEK_SMOKE_KEY` 才会发送虚构连通性请求；2026-09-26 已受控运行通过。App 内完整联调仍需专用测试儿童、脱敏样例、明确的远程处理/出境同意及 Key 持有人主动在设备中设置的测试 Key。
