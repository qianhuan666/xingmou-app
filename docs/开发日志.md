## 2026-09-23 阶段 2 领域与规则层

### 本次目标

### 已完成

- 扩展 `RiskEngine`，覆盖自伤、攻击、抽搐/癫痫、吞咽/呼吸困难、严重跌倒、意识异常、明显发育倒退、走失/陌生人风险、疑似急症 9 类风险。

## 2026-09-23 阶段 3.5 Agent 事件闭环与人机协同

### 本次目标

让 Agent 能够响应训练、风险、记录阈值、家长观察、审核和恢复事件，并把事件及其确定性处理结果写入本地审计链路。

### 已完成

- 新增 `AgentEvent` 事件模型，覆盖 `UserMessage`、`TrainingCompleted`、`ConsecutiveFailures`、`RiskDetected`、`RecordsThresholdReached`、`ParentObservationAdded`、`PlanRejected`、`ReviewApproved` 和 `SessionResumed`。
- 新增 `AgentEventProcessor`，将事件确定性路由到完成、暂停、安全停止、规划或等待审核状态。
- 儿童训练完成事件可生成 `TrainingRecordEntity`，并根据近期结果分别调整难度和支持等级。
- 连续失败、哭闹或疲劳事件进入暂停；高风险事件生成脱敏后的 `SafetyFlagEntity`，且不得继续训练。
- 达到 3 条有效记录时触发过程分析入口；数据不足时返回固定信息不足响应。
- 专业审核严格分为 `draft → confirmed → active` 两步；直接从草案激活会被拒绝。
- 方案退回必须填写理由，并同步更新方案版本和审核请求状态。
- 新增 `AgentEventCoordinator` 与 `RoomAgentEventStore`，在 Room 事务中保存事件、训练记录、风险标记、方案和审核结果。
- 新增 `AgentEventEntity` 和事件查询 DAO；Room 数据库升级到版本 2，并提供 1→2 无损迁移。
- `AgentRuntime` 支持从 Room 的运行、步骤和工具记录恢复，并重建幂等缓存，避免进程恢复后重复写入。
- 新增阶段 3.5 单元测试，覆盖儿童、家长、专业审核、暂停恢复、数据库记录映射和恢复幂等。

接入 Android 本地 TextToSpeech，让“小星”朗读儿童端安全短句，并提供朗读开关、语速、音量、大字体和高对比设置。

### 已完成

- 新增 `ChildSpeechController`，使用 Android `TextToSpeech` 和简体中文语言环境朗读儿童端短句。
- TTS 只接收 ViewModel/规则层已经确认的儿童端展示文案，不参与风险判断、难度调整或 Agent 决策。
- 初始化期间的首条朗读会进入待播队列，TTS 引擎就绪后自动播放，避免首次进入页面丢失语音。
- 新增朗读开关、0.75–1.25 倍语速、50%–100% 朗读音量控制。
- 新增大字体模式，将应用字体缩放到 1.15 倍，同时保留横竖屏滚动布局。
- 新增高对比配色，增强正文、边框、开关、滑块和主要操作的明暗差异。
- 辅助设置通过本机 `SharedPreferences` 持久化，不写入 Room，不进入 Agent Prompt，也不会上传外部服务。
- 在 Manifest 中声明 TTS 服务查询，兼容 Android 11 及以上包可见性要求。
- 公共表面、边框、小星标记和三端重点区域改为消费 Material 主题色，使高对比模式覆盖整个工作台。
- 新增语速与音量边界测试，防止异常设置超出安全范围。
