## 2026-09-23 阶段 2 领域与规则层

### 本次目标

在 Room 数据层之上建立确定性的风险路由、知识检索、训练任务控制、方案审核状态机和训练过程分析能力，为后续 Agent Runtime 提供可调用的安全边界。

### 已完成

- 扩展 `RiskEngine`，覆盖自伤、攻击、抽搐/癫痫、吞咽/呼吸困难、严重跌倒、意识异常、明显发育倒退、走失/陌生人风险、疑似急症 9 类风险。
- 增加结构化 `RiskAssessment`，保留原有 `assess()` 兼容入口，并实现安全停止优先于暂停、否定表达过滤和风险类型记录。
- 新增 `KnowledgeRetriever`：只检索已审核且启用的知识条目；总数最多 3 条、同领域最多 2 条；支持澄清、未找到、转介和安全停止路由。
- 新增 `TrainingEngine`：校验任务白名单、限制难度 1–5、控制单次最多调整 ±1 级、独立调整支持等级，并支持映射为 `TrainingRecordEntity`。
- 新增 `PlanStateMachine`：严格约束 `DRAFT → CONFIRMED → ACTIVE`，模型不能直接激活，退回/替代/归档必须由专业人员并填写理由。
- 新增 `AnalysisEngine`：计算正确率、首次正确率、平均反应时间、提示等级、独立完成率和趋势；有效记录少于 3 条不判断趋势，下降信号触发人工复核。
- 将 `DifficultyController` 难度范围从 1–10 收紧为 1–5。
- 新增阶段 2 单元测试，覆盖 9 类风险、暂停优先级、否定词、知识数量上限、任务白名单、难度边界、人工审核状态机和趋势复核。

## 2026-09-23 阶段 2.5 Agent Runtime 基础

### 本次目标

建立可被三端口和后续模型编排调用的最小 Agent Runtime，先固定工具白名单、端口授权、幂等调用和状态流转，避免模型直接执行高风险副作用。

### 已完成

- 新增 `ToolRegistry`：登记风险评估、知识检索、训练记录、过程分析和方案相关工具。
- 增加工具端口白名单、工具风险等级、人工审批要求和幂等键校验。
- 新增 `ExecutionStateMachine`：约束 `CREATED → ROUTING → PLANNING → EXECUTING_TOOL / WAITING_APPROVAL → VALIDATING → COMPLETED`，并支持暂停、失败和安全停止分支。
- 新增 `AgentRuntime`：管理运行快照、工具执行、幂等缓存、工具调用轨迹和状态步骤轨迹。
- 提供 `AgentRunEntity`、`AgentStepEntity`、`ToolCallEntity` 映射，能够写入阶段 1 已建立的 Room 审计表。
- 高风险工具（如方案激活）必须进入人工审批；安全停止状态禁止继续调用工具。
- 新增阶段 2.5 单元测试，覆盖未知工具、端口越权、安全停止、人工审批、越级状态、幂等调用和审计记录。
