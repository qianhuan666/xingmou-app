# V1.0 纯前端发布验收与待办

更新：2026-09-26。整个系统为 Android 纯前端单机应用，不建设自有服务端。专业端顶部的“机构 API Key”入口由设备使用者自行填写/清除 DeepSeek Key；Key 不预置源码、Git、BuildConfig 或 APK 常量。使用者已明确接受设备端 Key 可被提取的风险。

| 计划项 | 当前实现 | 剩余验收 |
| --- | --- | --- |
| E-1 Key 设置 | 专业端机构配置入口；当前设备本地保存/清除；不进入数据导出和日志；测试专用设置文件的保存/清除仪器测试通过 | 卸载与重装行为检查 |
| E-1 纯前端直连 | DeepSeek JSON 模式直连；本地儿童绑定和远程 AI 同意；脱敏、超时、暂态重试、HTTP 错误分类、Agent 校验/降级；模拟 HTTP 单元测试通过 | 专用测试 Key 的真实联调；弱网/断网人工验收 |
| E-1 费用 | 客户端输入长度和输出 token 上限；策略层保留粗略费用参数 | 无服务端配额或精确计费，真实账单与账户限额由 Key 持有人在 DeepSeek 平台管理 |
| E-2 数据权利 | 当前儿童 JSON/CSV 导出、删除事务及报告 | 补充能力档案、方案、审核和同意记录等导出范围；唯一儿童删除策略、恢复流程 |
| E-3 Agent 指标 | 按儿童计算基础指标；缺人工依据标注时显示未采样 | 标注流程、审计回放页面与人工验收 |
| E-4 试点发布 | 本地训练不依赖云端 AI | 真实测试儿童与明确出境授权、APK/日志隐私扫描、真机/TalkBack、签名包与回滚包 |

## 使用边界

- 未填 Key、当前儿童未授权或无远程 AI 同意时，使用本地安全模式，不向 DeepSeek 发请求。
- 设备本地保存 Key 不等于服务端保密；Root、设备备份、调试或恶意应用等情形可能导致泄露。设置和清除由 Key 持有人管理。旧 Key 若已分享，应先轮换。
- 仅发送经过本地最小化和脱敏的上下文；真实 AI 返回仍须通过 JSON、来源、端口和人工审核门。
- 当前本地角色与儿童绑定不构成服务端强身份认证；不宣称跨设备组织权限或统一账单配额。
- 导出文件由使用者选择位置并自行保管，删档不会删除已另存的副本。

## 发布条件

专用测试 Key 的受控联调、真实数据授权、隐私扫描、真机/TalkBack、内部试点签名包和回滚包完成前，仍不得宣称 V1.0 正式发布完成。无需提供服务器部署环境。
