# V1.0 发布验收与阻断项

更新：2026-09-26。依据《项目结束执行开发计划》第 7 节阶段 E。本文件区分“仓库内实现”与“真实试点发布验收”，不把本地模拟视作生产 AI。

| 计划项 | 当前证据 | 结论 |
| --- | --- | --- |
| E-1 API Key 不下发 APK | 已删除 Gradle 的 `DEEPSEEK_API_KEY` BuildConfig 注入；默认仅本地安全模型 | 本地代码已收紧；需对发布 APK 做最终密钥扫描 |
| E-1 服务端 Gateway | 仅有 Android 前置 `GatewayPolicy` 与可注入的 `PolicyBackedModelGateway`；没有服务端身份、短期令牌、限流/配额/审计部署 | 阻断 |
| E-1 同意与儿童授权 | Android 前置同意检查与脱敏已做；服务端尚未二次校验，撤回后重试已在前置层拦截 | 阻断 |
| E-1 超时、重试、响应校验与降级 | 本地策略限时与仅暂态重试；Agent JSON 校验失败可降级 | 部分完成，真实 HTTP/服务端验证未做 |
| E-2 儿童范围 JSON/CSV 导出 | 当前儿童、显式同意、字段白名单、所选实体全量查询、系统选定文件保存 | 部分完成；尚未覆盖能力档案、方案、审核和同意记录等全部儿童数据 |
| E-2 儿童删除 | 二次确认；删除请求、清理、结果同一 Room 事务 | 部分完成；唯一儿童不能删除，残留导出文件由用户控制，服务端同步未做 |
| E-2 按用途同意 | 已有远程 AI/导出同意；训练、共享、研究/试点未实现独立授权与撤回闸门 | 阻断 |
| E-3 Agent 指标 | 已记录运行摘要并可按儿童计算基础指标；无依据判断率因缺人工标注返回未采样 | 部分完成；需要标注流程与仪表盘验收 |
| E-4 真实 DeepSeek 联调 | 未执行，也未用真实儿童资料请求 | 阻断；需专用测试儿童、明确出境同意、费用上限、超时、测试后轮换 Key |
| 阶段 E 出口 | 本地训练可在无远程 AI 时运行；尚无生产 Gateway、内部试点包/回滚包及完整人工验收 | 未通过，不可宣称 V1.0 发布完成 |

## 完成发布前的外部输入

1. 确定服务端部署环境、用户身份与儿童授权来源、短期凭证签发/撤销方案，并提供可联调的测试环境；服务端须独立实现同意、授权、脱敏、限流、配额、审计和响应校验。
2. 对历史提供过的 DeepSeek 长期 Key 做撤销/轮换；不要把新 Key 发在聊天或纳入 APK/Git，改由服务端密钥管理注入。
3. 提供专用测试儿童、脱敏样例、明确的数据出境同意与费用上限；完成可复核的真实联调记录。
4. 明确唯一儿童删除的业务策略、导入恢复是否属于 V1.0 范围，以及训练/共享/研究同意的撤回后处理规则。
   同时确认数据权利导出应覆盖的实体和保留/脱敏字段；当前导出限于儿童基本档案、训练记录、家庭任务与反馈、量表及个案阶段，不等于数据库全量备份。
5. 完成隐私与 APK 扫描、真机和 TalkBack 人工验收、内部试点签名包与回滚包；记录结果后再决定发布。

## 安全边界

Android 端直连 `DeepSeekClient` 及密钥工厂已移除；远程 AI 状态保持未配置。生产环境不得在 Android 端持有供应商主密钥。导出文件位于用户选择的系统目的地，删除应用内儿童数据不会删除用户自行保存的导出副本；界面已明确这一点。
