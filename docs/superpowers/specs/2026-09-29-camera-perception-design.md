# 儿童端摄像头感知系统设计

## 1. 概述

在儿童训练模式下开启前置摄像头，端侧实时识别儿童的表情、头部姿态、人体动作、手势及手物交互状态。识别结果用于：

- **实时反馈**：轻度异常温和语音提示，情绪崩溃等极端情况才暂停任务
- **事后记录**：全程结构化记录，生成训练感知报告供专业人员/家长查看

**核心约束**：

- 端侧推理（MediaPipe Tasks），不上传视频，零 API 费用，儿童隐私不出设备
- 默认后台静默采集，儿童看不到摄像头画面，减少分心
- 不存原始视频，只存结构化状态数据
- 不影响核心训练功能：摄像头权限被拒或低端机降级时，训练照常运行

## 2. 整体架构

五层单向流水线：

```
UI (ChildScreen)
   │ CameraX 帧流                │ 反馈/暂停事件
   ▼                             ▼
感知层 (PerceptionManager)
   Face / Pose / Hand Landmarker
   └─ 每帧融合输出 PerceptionFrame
        ▼
判断层 (StateAnalyzer)
   表情状态机 / 专注度 / 动作分类 / 手势识别 / 手物交互启发式
        ▼
反馈层 (FeedbackController)
   L0 正常 / L1 轻度 / L2 中度 / L3 极端（崩溃才暂停）
        ▼
记录层 (SessionRecorder)
   每秒采样状态快照 → Room 存储 → 事后报告
```

**职责边界**：

- 感知层：只输出"看到了什么"（关键点 + blendshapes），不做判断
- 判断层：把原始感知映射为语义状态，不碰 UI
- 反馈层：根据状态级别决定是否介入，由分级策略控制
- 记录层：独立旁路，不影响实时性

## 3. 技术选型

**MediaPipe Tasks for Android**，原因：

- Google 出品，端侧零费用
- Face Landmarker 直接输出 468 面部关键点 + 52 个 blendshapes，表情可直接分类
- Pose Landmarker 输出 33 个人体关键点
- Hand Landmarker 输出 21 个手部关键点
- 同时覆盖表情 + 姿态 + 手势，是唯一端侧成熟方案

**已知限制**：

- 手物交互（拿取/放置/拼图正确与否）端侧无成熟方案，仅做启发式"在做什么动作"判断，无法判断"操作是否正确"
- 同时跑三个模型中端机约 15-25 FPS，低端机 < 10 FPS 时自动降级只开 Face
- APK 增大约 15-20MB

## 4. 识别与判断逻辑

### 4.1 表情状态（Face Landmarker blendshapes）

| 状态 | 判定条件 | 处理级别 |
|---|---|---|
| 开心 | `mouthSmileLeft/Right` 高分 | L0 记录 |
| 难过 | `browDownLeft/Right` + `mouthFrown` | L1 记录+轻度提示 |
| 生气 | `browDown` + `jawOpen` + 持续皱眉 | L1 记录+轻度提示 |
| 惊讶 | `jawOpen` + `eyeWide` 瞬时高分 | L0 记录 |
| 害怕 | `eyeWide` + `browUp` + `mouthFrown` | L1 记录+轻度提示 |
| 厌恶 | `noseSneer` + `mouthLeft/Right` | L0 记录 |
| 中性 | 其余 | L0 记录 |
| 闭眼 | `eyeBlinkLeft/Right` 高分 | 专注度用 |
| 眨眼 | `eyeBlink` 瞬时 | 记录 |
| 嘟嘴 | `mouthPucker` 高分 | 记录 |
| 说话 | 嘴部关键点持续运动 | 记录 |
| 打哈欠 | `jawOpen` + `eyeBlink` + 头部后仰 | L1 轻度提示 |
| 哭泣 | 难过 + 闭眼 持续 > 5s | L2 中度提示 |
| 大笑 | 开心 + 张嘴 持续 | L0 记录 |
| 崩溃 | 难过/生气 + 闭眼/张嘴 + 头部剧烈晃动 持续 > 5s + 置信度 > 0.7 | L3 暂停 |

### 4.2 头部姿态与专注度

| 状态 | 判定 |
|---|---|
| 正视屏幕 | pitch/yaw 在 ±25° |
| 抬头/低头 | pitch > 25° / < -25° |
| 左转/右转头 | yaw > 25° / < -25° |
| 歪头 | roll > 25° |
| 视线方向 | 左/右/上/下/中心（基于眼球 blendshapes） |
| 专注 | 正视 + 视线中心 持续 |
| 走神 | 头部偏离或视线偏离 > 5s |
| 睡着 | 闭眼 > 10s |
| 剧烈晃动 | pitch/yaw 短时间变化幅度大（崩溃判定用） |

### 4.3 人体动作（Pose Landmarker 33 点）

| 动作 | 判定 |
|---|---|
| 举手（左/右） | 腕高于头 |
| 双手举起 | 双腕均高于头 |
| 指认（左/右） | 食指伸展 + 手臂前伸 |
| 拍手 | 双腕距离 < 阈值 + 上下运动 |
| 点头 | pitch 周期变化 |
| 摇头 | yaw 周期变化 |
| 双手叉腰 | 双腕在腰部附近 + 肘外展 |
| 双手抱头 | 双腕在头部两侧 |
| 摸脸 | 手腕接近面部区域 |
| 摸头 | 手腕在头顶区域 |
| 站立/坐下 | 髋/膝/踝关键点角度 |
| 弯腰 | 躯干前倾 |
| 转身 | 肩宽与髋宽比例变化 |

### 4.4 手势（Hand Landmarker 21 点）

| 手势 | 判定 |
|---|---|
| 数字 0-10 | 手指伸展数量组合 |
| 点赞/不点赞 | 拇指伸展方向 |
| OK | 拇指食指相触 + 其余伸展 |
| 比心 | 双手拇指食指交叉 |
| 剪刀石头布 | 标准手势模板 |
| 胜利（V） | 食指中指伸展 |
| 拳头 | 全握拳 |
| 手掌张开 | 全伸展 |
| 食指指人 | 仅食指伸展 |
| 勾手指 | 仅食指弯曲 |

### 4.5 手物交互（启发式）

| 状态 | 判定 |
|---|---|
| 接近目标 | 手进入目标区域 |
| 操作中 | 手在目标区域停留 > 1s |
| 拿起 | 手进入 + 握拳 |
| 放下 | 握拳 → 张开 + 在目标区域 |
| 移动 | 手握拳 + 位置变化 |
| 双手协作 | 双手同时在目标区域 |
| 离开 | 手离开目标区域 |

## 5. 反馈控制层

### 5.1 分级策略

| 级别 | 触发条件 | 动作 | 冷却 |
|---|---|---|---|
| L0 正常 | 无异常 | 无 | — |
| L1 轻度 | 走神、小动作、难过/生气不持续 | 语音温和提示，不打断任务 | 30s |
| L2 中度 | 持续走神 > 30s、持续难过 > 15s | 语音提示 + 小星表情变化，不打断 | 60s |
| L3 极端 | 情绪崩溃（大哭大闹 > 5s）、睡着 > 15s | 暂停任务 + 语音安抚 + 引导 | 暂停直到手动恢复 |

### 5.2 触发规则

- **防抖**：所有判定需持续 N 帧（约 0.5-1s）才触发
- **冷却**：同级别反馈后进入冷却，不重复触发
- **升级**：L1 持续不缓解可升级到 L2
- **极端优先**：L3 立即执行，不受冷却限制

### 5.3 反馈形式

- 语音：复用现有 TTS，温和语气，短句
- 界面：小星头像表情随状态变化
- 不弹模态框，不强制交互

## 6. 记录与报告层

### 6.1 实时记录

- 每秒采样一次状态快照：`{时间, 表情, 专注度, 动作, 手势, 手物状态}`
- 内存环形缓冲（最近 10 分钟），训练结束写入 Room

### 6.2 Room 存储

表 `perception_session`：

| 字段 | 类型 | 说明 |
|---|---|---|
| session_id | String | 主键 |
| child_id | String | 儿童 ID |
| start_time | Long | 开始时间戳 |
| end_time | Long | 结束时间戳 |
| snapshots | String (JSON) | 状态快照时序 |
| summary | String (JSON) | 汇总统计 |

不存原始视频帧。

### 6.3 事后报告

- 表情分布（开心/难过/生气/中性占比）
- 专注度曲线（专注时长、走神次数、平均专注时长）
- 动作统计（各动作次数和时长）
- 手势统计（各手势次数）
- 交互摘要（操作次数、平均操作时长）
- 异常事件（崩溃次数、暂停次数、时段分布）
- 整体评分（专注度、情绪稳定性、参与度）

## 7. UI 集成与权限

### 7.1 摄像头预览

- 默认隐藏：儿童训练时不显示画面
- 专业入口：设置区「感知监控」开关，开启后右下角显示 120dp 圆形小窗
- 小窗点击放大全屏，叠加识别结果（表情标签、姿态骨架、手势标注）

### 7.2 权限

- AndroidManifest 声明 `CAMERA` 权限
- 首次进入儿童端申请，通过后记住
- 拒绝权限：感知层不启动，训练照常

### 7.3 与现有儿童端集成

- `ChildScreen` 新增 `PerceptionOverlay` 叠加组件
- `ChildUiState` 新增：`perceptionEnabled`、`perceptionPreviewVisible`、`currentEmotion`、`currentFocusLevel`、`currentAction`
- `XingmouViewModel` 新增：`togglePerception()`、`togglePreview()`、感知事件回调入口
- 训练开始自动启动感知，训练结束自动停止并保存

### 7.4 性能与降级

- 中端机：Face + Pose + Hand 全开（~20 FPS）
- 低端机 FPS < 10：自动降级只开 Face
- 后台采集不渲染预览帧到屏幕

### 7.5 隐私

- 不存原始视频，只存结构化状态
- 不上传感知数据
- 设置里可一键清除感知记录

| 模块 | 职责 | 依赖 |
|---|---|---|
| `PerceptionManager` | CameraX 帧采集 + MediaPipe 三模型推理 + 帧融合 | CameraX, MediaPipe Tasks |
| `PerceptionFrame` | 单帧感知结果数据类 | — |
| `StateAnalyzer` | 表情/专注度/动作/手势/手物状态判断 | PerceptionFrame |
| `PerceptionState` | 判断结果数据类 | — |

| `PerceptionOverlay` | 摄像头预览 + 识别结果叠加 UI | CameraX PreviewView |
